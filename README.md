# Zayor Clothing — Desarrollo de Interfaz Web

Interfaz web interactiva y adaptable para la marca de ropa Zayor Clothing:
catálogo de prendas por categorías, detalle de producto y un flujo de compra
**simulado** (sin pagos ni pedidos reales).

**Equipo:** José Cely y Juan Diego González  
**Tecnologías:** HTML5, CSS3, JavaScript/React, Tailwind CSS y Figma

## Instalación

```bash
git clone <URL-del-repositorio>
cd zayor-clothing-web
npm install
npm run dev
```

## Scripts

| Comando                | Qué hace                                |
| ---------------------- | --------------------------------------- |
| `npm run dev`          | Abre el proyecto en modo desarrollo     |
| `npm run build`        | Genera la versión de producción         |
| `npm run lint`         | Revisa el código con ESLint (Airbnb)    |
| `npm run format`       | Da formato al código con Prettier       |
| `npm run format:check` | Comprueba el formato sin modificar nada |

## Cómo trabajamos

Las reglas del equipo están en [ESTANDARES.md](ESTANDARES.md): convención de
commits, ramas, Definition of Ready, Definition of Done y política de revisión.
Nadie hace commit directo a `main`: todo entra con Pull Request revisado por la
otra persona del equipo.
